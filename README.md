# Dropper

영상의 무게를 덜어내는 Windows·Mac 영상 압축 앱입니다.<br>
파일 하나부터 하위 폴더의 영상 전체까지, 내 컴퓨터에서 압축합니다.<br>
예상 용량과 실제 절감량을 확인하고, 원본은 그대로 보관합니다.

## 퀵스타트

1. 기기에 맞는 설치 파일을 받습니다: **[Windows](https://github.com/lsy980326/Dropper/releases/download/v0.2.1/Dropper_0.2.1_Windows_x64_setup.exe)** · **[Mac Apple Silicon](https://github.com/lsy980326/Dropper/releases/download/v0.2.0/Dropper_0.2.0_macOS_AppleSilicon.dmg)** · **[Mac Intel](https://github.com/lsy980326/Dropper/releases/download/v0.2.0/Dropper_0.2.0_macOS_Intel.dmg)**. 일반 사용에는 설치 파일만 필요합니다.
2. 앱을 열고 영상이나 폴더를 끌어놓습니다. 압축 강도를 고르고 **예상 용량 확인**으로 미리 확인할 수 있습니다.
3. **영상 압축**을 누릅니다. 결과는 원본 폴더의 `Compressed`에 저장됩니다.

Mac Apple Silicon은 macOS 26 이상, Intel은 macOS 12 이상이 필요합니다. 인증서 서명·Apple 공증을 하지 않은 빌드이며, Intel Mac의 실제 실행은 아직 검증하지 않았습니다.
