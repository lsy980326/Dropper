# Dropper

영상의 무게를 덜어내는 Windows·Mac 영상 압축 앱입니다.<br>
파일 하나부터 하위 폴더의 영상 전체까지, 내 컴퓨터에서 압축합니다.<br>
예상 용량과 실제 절감량을 확인하고, 원본은 그대로 보관합니다.

## 퀵스타트

1. 기기에 맞는 설치 파일을 받습니다: **[Windows](https://github.com/lsy980326/Dropper/releases/download/v0.2.3/Dropper_0.2.3_Windows_x64_setup.exe)** · **[Mac Apple Silicon](https://github.com/lsy980326/Dropper/releases/download/v0.2.3/Dropper_0.2.3_macOS_AppleSilicon.dmg)** · **[Mac Intel](https://github.com/lsy980326/Dropper/releases/download/v0.2.3/Dropper_0.2.3_macOS_Intel.dmg)**. 일반 사용에는 설치 파일만 필요합니다.
2. 앱을 열고 영상이나 폴더를 끌어놓습니다. v0.2.3은 목표를 고르면 영상마다 맞춤 추천을 자동 적용합니다. 세부 설정에서 장치·처리 강도·동시 작업을 직접 고를 수도 있습니다.
3. **영상 압축**을 누릅니다. 작업 중에는 진행률만 표시하며 **자세히 보기**로 목록을 볼 수 있습니다. 결과는 원본 폴더의 `Compressed`에 저장됩니다.

Mac Apple Silicon은 macOS 26 이상, Intel은 macOS 12 이상이 필요합니다. Mac 설치 파일은 임시 서명을 적용했으며 Apple 공증을 하지 않은 빌드입니다.
